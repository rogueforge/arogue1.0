The only known copy of the 1.0 source came to the Rogue Restoration
Project from a player, as a DOS archive of a tree last built at some
other site. The restore point is that tree with its 8.3 file names
put back to the names its Makefile and #includes give them
(mach_dep.h, new_level.c, monst_show.c, Tolower.c, Makefile) and its
CRLF line endings made LF. Nothing else is changed.
